# Sussex eDNA Bioinformatics Pipeline

An automated environmental DNA (eDNA) metabarcoding pipeline that converts raw NCBI SRA sequencing data into taxonomically annotated species tables.

---

## Repository contents

This repository includes:

- The complete Sussex eDNA bioinformatics pipeline
- Benchmark NCBI SRA sequencing data
- An example annotated species table (`master_species_composition.csv`)
- The original Nature Metrics reference dataset (`reference_data.xlsx`)

---

## Requirements

Install:

- Python 3.11+
- SRA Toolkit
- Cutadapt
- USEARCH v12+

Then install the Python packages:

```bash
pip install -r requirements.txt
```

---

## Running the pipeline

Make the launcher executable:

```bash
chmod +x run_pipeline.sh
```

Run the complete workflow:

```bash
./run_pipeline.sh
```

The pipeline automatically performs:

1. SRA → FASTQ conversion
2. Primer trimming
3. Dereplication
4. Denoising
5. BLAST identification
6. NCBI taxonomy annotation

---

## Output

A new results folder is created inside:

```
runs/
```

The final output file is:

```
master_species_composition.csv
```

On supported Linux systems, this file opens automatically when the pipeline finishes.

---

## Included example files

If you simply wish to inspect the benchmark results without running the pipeline, the repository already includes:

- `master_species_composition.csv` — the completed taxonomic annotation generated by the pipeline.
- `reference_data.xlsx` — the original Nature Metrics reference report used for comparison and validation.
